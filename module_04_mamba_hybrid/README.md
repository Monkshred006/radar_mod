# Module 4 — PhotonShield Mamba-Hybrid Engine

## 1. Overview

Module 4 (**PhotonShield Mamba-Hybrid Engine**) is the primary learnable AI module of the PhotonShield AI project. It processes structured sensor tokens $[B, T, S, D_{features}]$ generated by Module 3 and models long-range temporal dynamics together with cross-sensor group interactions to produce task-agnostic latent sequence and pooled representations $[B, D_{model}]$.

```
                 MODULE 3
                     │
                     ▼
        [B,T,S,D_features]
                     │
                     ▼
              Input Projection
                     │
                     ▼
        [B,T,S,D_model]
                     │
          ┌──────────┴──────────┐
          │                     │
          ▼                     ▼
     MAMBA BRANCH        SENSOR INTERACTION
          │                     │
          │                  across S
          │                     │
          ▼                     ▼
      Temporal              Cross-sensor
      modeling              interaction
          │                     │
          └──────────┬──────────┘
                     ▼
                Fusion
                     │
                     ▼
                   FFN
                     │
                     ▼
                Residual
                     │
                     ▼
              Repeat N times
                     │
                     ▼
             [B,T,D_model]
                     │
                     ▼
             Masked Pooling
                     │
                     ▼
               [B,D_model]
                     │
                     ▼
               Task Heads
```

## 2. Architecture Components

### Temporal Mamba SSM Branch
- **Purpose**: Models long-range temporal dependencies $x_1 \to x_2 \to \dots \to x_T$ in $O(T)$ time without quadratic attention complexity.
- **Dual-Backend Support**:
  - `MambaBackend`: Native CUDA `mamba_ssm` package when GPU extensions are present.
  - `FallbackSSMBackend`: Pure PyTorch selective State-Space Model implementation (causal 1D conv + selective discretization + recurrent scan) for CPU and development fallback.

### Cross-Sensor Interaction Branch
- **Purpose**: Models instantaneous physical relationships between sensor modalities (e.g. `optical` $\leftrightarrow$ `motion`, `optical` $\leftrightarrow$ `distance`).
- **Operation**: Reshapes $[B, T, S, D_{model}] \to [B \times T, S, D_{model}]$ and executes lightweight multi-head self-attention across the sensor group dimension $S=5$.

### Task Heads
- `ClassificationHead`: $[B, D_{model}] \to [B, \text{num\_classes}]$
- `RegressionHead`: $[B, D_{model}] \to [B, \text{num\_outputs}]$
- `MultiTaskHead`: Shared latent vector $\to$ classification & regression predictions.

## 3. Quick Usage Example

```python
import torch
from module_04_mamba_hybrid import PhotonMambaHybrid, MambaHybridConfig, ClassificationHead

# 1. Initialize Engine
config = MambaHybridConfig(d_model=128, num_layers=2)
engine = PhotonMambaHybrid(config)
head = ClassificationHead(d_model=128, num_classes=2)

# 2. Forward pass with Module 3 output dictionary
output = engine(module3_output)
pooled_latents = output["pooled_output"]  # [B, D_model]

# 3. Task head prediction
logits = head(pooled_latents)  # [B, 2]
```

## 4. Dual Backend & Future BitNet Strategy

- **Backend Selection**: Set `config.backend = "auto"`, `"mamba-ssm"`, or `"fallback"`.
- **BitNet Readiness**: All linear layers (`input_projection`, `FFN`, `heads`) are isolated inside standard PyTorch `nn.Linear` modules, allowing drop-in replacement by `BitLinear` (1.58-bit ternary weights) in subsequent quantization modules without restructuring Module 4.
